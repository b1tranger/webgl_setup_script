# Lab 1: WebGL 2.0 RGB Triangle

## Overview
Demonstrates core modern graphics pipeline concepts under WebGL 2.0:
- GLSL ES 3.00 Shaders (`#version 300 es`)
- Vertex Array Object (VAO) and Vertex Buffer Object (VBO) state management
- Interpolated vertex colors across a rasterized polygon
- Interleaved vertex attribute pointers (`glVertexAttribPointer`)

## How to Build & Run
Double-click `build.bat` or run:
```cmd
build.bat
```
or with Make:
```bash
make run
```
This builds into `dist/` and runs a local server at `http://localhost:8080`.
